# Характеристики iPhone

`import_iphones` сохраняет плоский словарь характеристик и регистрирует метаданные
в `Attribute`, привязывая их к категории `iphone`. Схема определена в
`src/apps/products/iphone_specifications_v1.py`: русские названия, группы,
порядок и единицы измерения. Признаки поддержки используют enum `Да` / `Нет`.
Этот модуль используется миграцией 0019 и должен оставаться неизменным;
для последующих изменений схемы нужна новая версия и миграция.

API возвращает `specifications` в порядке атрибутов, затем неизвестные поля.
Каждая зарегистрированная характеристика содержит `sort_order`, `group_name`,
`unit` и `value`. Числа могут приходить числом или строкой (после админки).
У неизвестных характеристик `id` равен `null`; стабильный ключ интерфейса — `slug`.
Фронт группирует характеристики, форматирует числа и boolean, а пустые значения
показывает как «Не указано». Дата создания записи в блоке не отображается.

## Обновление установленного приложения

1. Сохранить резервную копию базы штатным способом используемой СУБД.
2. Установить обновлённый бэк и выполнить в его окружении:

   ```sh
   python manage.py migrate
   ```

3. Собрать и развернуть обновлённый фронт обычным способом проекта.

Миграция 0019 преобразует существующие характеристики только категории `iphone`.
Она не запускает импорт каталога, не меняет остальные поля товаров, варианты или
медиа. Неизвестные поля и конфликтующие значения сохраняются. Повторное
преобразование не меняет нормализованные значения. Обратная миграция не
предусмотрена: для полного отката данных нужна резервная копия.

Админка сохраняет неизвестные характеристики при редактировании зарегистрированных.
XLSX-импорт не изменён и не входит в этот процесс.

## Проверки

Бэк: `python manage.py test apps.products apps.cart --noinput`.
Фронт: `node --test tests/productSpecifications.test.mjs` и `pnpm typecheck`.
